# DNA Methylation Array Analysis Pipeline for Alzheimer's Disease

This repository is a small, reproducible methods demonstration for analysing human brain DNA methylation array data from Alzheimer's disease cases and controls. It is a portfolio project for learning methylation arrays, R Markdown, and R Shiny.

This is **not a claim of biological discovery**. All results in the final report will be generated by code from a verified public GEO dataset and interpreted as exploratory.

## Status

Milestone M2 is complete. The initially proposed GSE80970 and GSE59685 records were checked and their series `RAW.tar` files contained only GPL13534 platform resources, not sample IDAT files. The project therefore uses the verified GSE212682 record instead.

### Selected dataset

- Accession: GSE212682
- Platform: Illumina Infinium MethylationEPIC 850K array
- Study tissue: eight human brain regions from 47 individuals
- Analysis tissue: one prefrontal-cortex region selected after inspecting the available region labels
- Selection rule: retain the selected brain region with non-missing diagnosis-related status, age, sex, batch, and IDAT fields; exclude the intermediate `conf_diag = 1` category; use a fixed seed of `20261003` to select five controls and five Alzheimer's disease cases. The smaller subset is a transparent laptop-memory constraint for raw EPIC import, not a biological exclusion criterion.
- Raw data: `GSE212682_RAW.tar`, downloaded by `scripts/00_download_data.R` and never committed to Git.

The diagnosis variable will be defined from the verified GSE212682 metadata field used by the script. Neuropathology fields will be retained as metadata and discussed separately; they will not be silently treated as the same variable as clinical diagnosis.

### M2 results

The 10-sample subset was normalized with minfi Noob. Filtering retained probes that passed the detection-p threshold in at least 80% of samples, were autosomal, and had no annotated CpG or single-base-extension SNP. The allowed package set does not provide a validated EPIC cross-reactive-probe list, so that filter is explicitly recorded as not applied; no unverified list was substituted. Missing beta values were checked after filtering and no imputation was needed. Exact counts are in `results/probe_filter_counts.tsv`.

## M0: verify the dataset

Open these records in a browser:

- [GSE80970](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE80970)
- [GSE59685](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE59685)

For each record, record the following from the GEO page and supplementary files section:

- platform: Illumina 450K or EPIC;
- whether raw IDAT files are available;
- total sample count;
- whether sample metadata contain diagnosis or neuropathology status, age, sex, and brain region;
- whether Sentrix ID and array position are available, or whether batch can be represented another way.

Do not download or commit raw IDAT files yet. Paste the observations into the project discussion or terminal notes before we select a dataset.

## Planned workflow

After dataset verification, the project will be built milestone by milestone:

1. download and document the selected data;
2. import IDATs and perform sample QC;
3. normalise and filter probes;
4. explore batch effects and perform differential methylation analysis;
5. run exploratory enrichment and render the report;
6. build the Shiny app and perform a clean reproducibility run.

## Environment

The current target environment is macOS, R 4.5.2, 16 GB RAM, internet access, and terminal-based execution. Package versions will be pinned with `renv` after the dataset decision.

## Important data rule

Raw IDAT files and other large downloaded files belong under `data/raw/` and are ignored by Git. Clean metadata, scripts, figures, tables, and report outputs may be committed when they are generated and reviewed.
